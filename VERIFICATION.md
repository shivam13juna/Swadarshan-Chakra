# Implementation verification

Validated on this Mac with macOS 27.2, Apple Silicon, and Swift 6.3.3. The app's deployment target is macOS 13.0. The delivered bundle is version 1.3.0 (build 7), a local, ad-hoc-signed release build for Apple Silicon. Version 1.3.0 adds freestyle (no timer), a "Show countdown bar" setting, key hints on the pause screen, practiced time that includes pauses spent with the practice, a three-second card before each step on which the supplied cycle of ages shows where that step stands (its white hour hand turning there from the last step's place), and a table on the completion screen of the time spent in each step of each cycle. Version 1.2.0 changed stage 4's context to संगम युग में, adds a cycle counter above the step counter, orders the shortcut hints like their buttons, adds total-time entry, opens every cycle with a three-second card, and lets meditation run in an ordinary window: the standard window buttons are shown, leaving full screen (green button, View ▸ Exit Full Screen, ⌃⌘F) keeps the meditation open, and an "Open in full screen" setting (on by default) decides how it opens. The native full-screen smoke test has been updated for these changes, including new checks for leaving full screen and for the setting, but was not re-run on 1.2.0 or 1.3.0, because it takes over the display for about 45 seconds; its last passing run was on version 1.1.1. It has since been updated for closing that ends the practice, for selecting a field's value on click, for Esc resuming a paused practice, for freestyle, for pauses counting as practice while the window is in front, and for the cards before steps, and has not been run with those changes either. Both GitHub workflows run on GitHub: for commit 2063191, the release workflow rebuilt and published version 1.2.0, and the website workflow deployed the site. Since 1.3.0 every practice is kept on the device; the journey, below the setup screen and in the circle's place on completion, shows the history; and a backup file carries it between the Mac app and the website in either direction. The smoke test has not been run with these changes, and does not touch the practice history.
